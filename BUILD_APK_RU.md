# Как получить APK ReverseScan

## Вариант A — GitHub Actions (без установки Android Studio)

1. Создайте **приватный** репозиторий GitHub, например `ReverseScanAndroid`.
2. Загрузите в репозиторий всё содержимое этой папки, включая скрытую папку `.github`.
3. Откройте вкладку **Actions** и разрешите запуск workflows, если GitHub попросит.
4. Запуск сборки произойдёт автоматически после push в `main`/`master`. Также можно открыть workflow **Build Android APK** и нажать **Run workflow**.
5. После успешной сборки откройте запуск workflow, найдите **Artifacts** и скачайте `ReverseScan-debug-apk`.
6. Распакуйте архив и установите `app-debug.apk` на телефон. Android может попросить разрешить установку из используемого файлового менеджера.

## Вариант B — Android Studio

1. Установите Android Studio и Android SDK Platform 35.
2. Откройте папку проекта `ReverseScanAndroid`.
3. Установите JDK 17 или выберите встроенный JBR Android Studio.
4. Выполните Gradle Sync.
5. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Важные ограничения текущей версии

Это устанавливаемая тестовая сборка прототипа захвата глубины (v0.2.0), а не завершённый метрологический/CAD-комплекс. Она показывает ARCore-камеру, собирает depth-derived облако точек по нескольким ракурсам и экспортирует PLY. В этой версии ещё нет реконструкции замкнутой поверхности, STL/3MF/STEP, точных измерительных инструментов и редактора ответных деталей. Перед использованием на реальных объектах необходима проверка на Samsung Galaxy S24 Ultra и контроль размеров независимым измерительным инструментом.

GitHub Actions создаёт **debug APK**, подписанный тестовым ключом Android Gradle Plugin. Для распространения release APK потребуется отдельная подпись собственным keystore.
